# Healthcare-Analytics-SQL-Project

## 📌 Project Overview
This project involves designing a healthcare database and performing data analysis using SQL.

## 🛠️ Tools Used
- MySQL
- SQL

## 📊 Key Features
- Created relational database (Patients, Hospitals, Admissions, Treatments)
- Performed data analysis using joins, aggregation, subqueries, and window functions
- Built HospitalPerformance view for insights

## 📈 Insights
- Patient demographics analysis
- Hospital utilization tracking
- Treatment cost analysis
- Length of stay evaluation

- SQL Script
